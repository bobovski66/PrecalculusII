Six Trigonometric Functions

Module 2 · Six readings of the same point

The point (cos θ, sin θ) on the unit circle determines all six functions. Move the angle and watch the ratios. When a denominator is zero, the corresponding function is undefined—not zero or infinity.

Six function values

Discover

  1. Find a quadrant in which sine is positive but tangent is negative. Explain by coordinate signs.
  2. Rotate to 90° and 270°. Which ratios are undefined? Why?
  3. Compare 45° and 225°. Which values are unchanged and which have opposite signs?
  4. Why is the tangent line shown at x = 1? Relate its intersection height to sin θ / cos θ.

The line at x = 1 is intersected by the terminal ray only when cos θ is nonzero. Very large tangent values appear near 90° and 270°.
