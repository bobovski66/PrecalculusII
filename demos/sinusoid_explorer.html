Sinusoid Explorer

Module 3 · Amplitude, period, phase, and midline

Every parameter in y = A sin(B(x − C)) + D has a geometric job. Adjust the values and watch the curve. The viewing window automatically scales to keep the graph visible.

Dashed line: midline. Orange segment: one period. The plot always shows at least two complete cycles, centered near the phase shift.

Investigate

  1. Make A negative. What changes about the first quarter of the wave?
  2. Double B. Explain what happens to the period.
  3. Set C = 2, then C = −2. Why does this move the graph in the direction that it does?
  4. Vary D. What happens to the greatest and least possible values?
  5. Can you construct a wave with period π/2, amplitude 3, and midline −1?
